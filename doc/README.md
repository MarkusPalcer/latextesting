# LatexTesting Documentation

Choose a guide based on your role:

- **Users** write fixture tests and consume the framework as a black box. Start
  with the [user guide](user/README.md) or go directly to the
  [quick start](user/quick-start.md).
- **Developers** work on the framework itself. The
  [developer guide](developer/README.md) documents the implementation and
  development workflow.

LatexTesting delegates LaTeX compilation to its host project. The
[build lifecycle guide](developer/build-lifecycle.md) documents the host
compiler contract.
