# User Guide

These guides describe how to use LatexTesting without relying on its internal
implementation:

| Guide | Covers |
|---|---|
| [Quick Start](quick-start.md) | Create and run a first fixture test. |
| [Defining Tests](defining-tests.md) | Declare globally unique fixtures and named tests. |
| [Configuring Tests](configuring-tests.md) | Select fixtures and expected build outcomes. |
| [Tests](assertions.md) | Check compiler logs and report automated or manual tests. |
| [Inspecting PDFs](inspecting-pdfs.md) | Check generated PDFs with HexaPDF. |
| [Running Tests](running-tests.md) | Run tests through a host task or the public runner API. |
